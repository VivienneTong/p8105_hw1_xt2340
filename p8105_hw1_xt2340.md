# Problem 2

Create data frames

``` r
library(tidyverse)

set.seed(8105)

prob2_df = tibble(
  samp = rnorm(10),
  samp_gt_0 = samp > 0,
  vec_char = c("A", "B", "C", "D", "E", "F", "G", "H", "I", "J"),
  vec_factor = factor(c("Low", "Medium", "High", "Low", "Medium", "High", "Low", "Medium", "High", "Low"))
)
```

Take the mean of each column

``` r
mean(pull(prob2_df, samp))
mean(pull(prob2_df, samp_gt_0))
mean(pull(prob2_df, vec_char))
mean(pull(prob2_df, vec_factor))
```

``` r
as.numeric(pull(prob2_df, samp_gt_0))
as.numeric(pull(prob2_df, vec_char))
as.numeric(pull(prob2_df, vec_factor))
```

Analysis:

Means can be successfully calculated for the numeric variable (`samp`)
and the logical variable (`samp_gt_0`), where logical values are treated
as 1 (`TRUE`) and 0 (`FALSE`). Means cannot be calculated for the
character variable (`vec_char`) and factor variable (`vec_factor`),
resulting in `NA` values and warning messages.
